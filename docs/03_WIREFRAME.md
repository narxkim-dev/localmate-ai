```text
┌─────────────────────────────────────┐
│ LocalMate AI                        │
│ 부산·경주 관광 컨시어지            │
├─────────────────────────────────────┤
│ 지역 : [부산 ▼]                     │

├─────────────────────────────────────┤
│ 💬 채팅                            │
```

## 현재 구현 화면

- 새 대화 버튼
- 부산 / 경주 지역 선택
- 한국어 / 영어 / 일본어 / 중국어 선택
- SSE 기반 AI 답변 스트리밍
- Markdown 제목, 목록, 표 렌더링
- 여행 코스가 포함된 답변에만 PDF 다운로드 버튼 표시
- 모바일 반응형 레이아웃
