## 기능 시나리오

### 지역 및 언어

- 부산과 경주 선택값이 요청의 `region`에 반영되는지 확인한다.
- 한국어, 영어, 일본어, 중국어 선택값대로 답변하는지 확인한다.

### Streaming

- 응답이 완료될 때까지 SSE 조각이 동일한 AI 메시지에 순서대로 추가되는지 확인한다.
- 응답 중 추가 전송이 차단되는지 확인한다.
- 새 대화를 시작하면 진행 중인 요청이 취소되는지 확인한다.

### Chat Memory

- 동일 conversationId의 후속 질문에서 이전 추천 내용을 기억하는지 확인한다.
- 새 대화 이후 이전 대화 문맥이 섞이지 않는지 확인한다.

### Markdown 보안 및 표시

- 제목, 목록, 표가 올바른 HTML로 표시되는지 확인한다.
- AI가 반환한 HTML이 DOMPurify를 거쳐 정제되는지 확인한다.

### 여행 코스 PDF

- 코스 마커가 모두 존재하는 완료 답변에만 PDF 버튼이 나타나는지 확인한다.
- PDF에 마커 밖의 일반 대화가 포함되지 않는지 확인한다.
- 지역, 언어, 생성일과 상세 코스가 포함되는지 확인한다.
- 문단과 목록이 페이지 경계에서 반으로 잘리지 않는지 확인한다.
- 표와 일반 문장이 오른쪽 출력 영역 밖으로 넘치지 않는지 확인한다.
- 긴 표 셀이 셀 내부에서 줄바꿈되는지 확인한다.
